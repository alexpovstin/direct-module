# direct-module

Локальный модуль чтения данных Яндекс Директа. Веб-панель ведёт организации, подключения, рекламные аккаунты и разрешения. REST API принимает структурированные команды и базовые команды на русском языке.

## Запуск

В корне репозитория выполните в терминале VS Code или PowerShell

```powershell
uv sync --locked --python 3.12
uv run --locked alembic upgrade head
uv run --locked direct-module
```

Откройте [локальную панель](http://127.0.0.1:8000/). Для другого порта используйте `uv run --locked direct-module --port 8080`. SQLite по умолчанию хранится в `data/direct-module.sqlite3`. Путь к базе можно изменить через `DIRECT_MODULE_DB`, задав одинаковое значение при миграции и запуске.

## Первый реальный аккаунт

### Приложение и заявка в Директе

1. Проверьте под логином разработчика, есть ли уже подходящее OAuth-приложение, которому Директ одобрил доступ. Одобрение выдаётся на приложение. Одно одобренное приложение подходит для нескольких пользователей, каждый из которых выдаёт доступ отдельно. [Приложения OAuth](https://oauth.yandex.ru/), [Мои заявки в Директе](https://direct.yandex.ru/registered/main.pl?cmd=apiCertificationRequestList), [FAQ по заявкам](https://yandex.ru/dev/direct/doc/ru/troubleshooting/register)
2. Если подходящего приложения нет, в Яндекс OAuth выберите «Для доступа к API или отладки». Укажите название `Direct Module`, рабочую почту для связи и право «Использование API Яндекс Директа» (`direct:api`). Для авторизации от имени организации в Яндекс ID руководство Директа также указывает `passport:business`. В настройках платформы «Веб-сервисы» выберите URL для разработки либо укажите Redirect URI `https://oauth.yandex.ru/verification_code`. Сохраните приложение и скопируйте его `Client ID`. [Регистрация приложения](https://yandex.ru/dev/direct/doc/ru/concepts/register), [параметры ручной выдачи токена](https://yandex.ru/dev/id/doc/ru/tokens/debug-token)
3. В Директе под логином разработчика откройте «Настройки API» → «Мои заявки» → «Новая заявка». Выберите созданное приложение, укажите контактную почту и описание. Прочитайте условия, подтвердите согласие и отправьте заявку. Если раздел API недоступен, проверьте, что аккаунт Директа настроен и в нём создана хотя бы одна кампания. У Яндекса есть сценарий с черновиком кампании. [Подача заявки](https://yandex.ru/dev/direct/doc/ru/access-request), [настройка кабинета и черновик](https://yandex.ru/dev/direct/doc/ru/intro)

Текст для описания приложения в заявке

> Direct Module — локальный инструмент для сотрудников, обслуживающих рекламные аккаунты. Приложение использует OAuth от имени пользователя Директа для проверки доступа, получения списка аккаунтов, чтения баланса общего счёта и расходов. На основе полученных данных формируется финансовая сводка. Все обращения приложения к рекламным данным выполняются в режиме чтения.

Для реального запроса потребуется одобренная заявка. Получить токен можно до ответа по заявке. Яндекс указывает срок рассмотрения до семи дней. [Регистрация и рассмотрение заявки](https://yandex.ru/dev/direct/doc/ru/concepts/register), [порядок шагов](https://yandex.ru/dev/direct/doc/ru/access-request)

### Какой токен вставить в панель

1. Войдите в Яндекс под логином, чьи данные должен читать модуль. Для первой проверки баланса подойдёт логин существующего рекламодателя с доступом к общему счёту. Для агентского подключения токен получает представитель агентства. [Доступ и авторизация](https://yandex.ru/dev/direct/doc/ru/concepts/access), [роли пользователей Директа](https://yandex.ru/dev/direct/doc/ru/objects/roles)
2. Подставьте `Client ID` приложения в адрес `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`. Откройте этот адрес в браузере и нажмите «Разрешить». Возьмите значение `access_token` со страницы Яндекса. Яндекс называет этот способ ручным или отладочным. С одобренным приложением и подходящими правами токен работает с реальными данными. [Как получить OAuth-токен](https://yandex.ru/dev/direct/doc/ru/token), [формат ответа](https://yandex.ru/dev/id/doc/ru/tokens/debug-token)
3. Вставьте только `access_token` в поле `OAuth-токен` в [локальных подключениях](http://127.0.0.1:8000/#connections). Для ручного способа `Client ID` используется в адресе выдачи и в заявке, а `Client secret` относится к другим схемам OAuth. `DIRECT_MODULE_API_KEY` служит для вызова нашего модуля центральным «Интерфейсом». Токен и адрес страницы, содержащий `access_token`, не отправляйте в чат. [OAuth Яндекс ID](https://yandex.ru/dev/id/doc/ru/tokens/debug-token), [контракт модуля](API_CONTRACT.md)

Для чтения баланса модуль использует OAuth-токен пользователя и операцию `AccountManagement.Get`. Упоминаемые в документации мастер-токен и финансовый токен относятся к финансовым операциям вроде перевода средств и выставления счетов. [Термины API Директа](https://yandex.ru/dev/direct/doc/ru/concepts/glossary), [операция Get в Live 4](https://yandex.ru/dev/direct/doc/dg-v4/ru/live/AccountManagement_Get)

### Проверка баланса

1. В разделе «Организации» добавьте организацию. Название и псевдонимы можно использовать в текстовых командах. Сайт и привязки аккаунтов можно изменить позже.
2. В разделе «Подключения» задайте название и сценарий, вставьте OAuth-токен в защищённое поле и сохраните форму. Нажмите «Разрешить проверку и поиск», затем «Проверить авторизацию». Карточка покажет логин и тип, которые подтвердил Яндекс. Там же можно переименовать подключение.
3. Нажмите «Показать аккаунт токена» или «Получить список клиентов» для агентства. Действие «Проверить доступ к другому аккаунту» отправляет введённый логин в Яндекс с токеном этого подключения. При успехе аккаунт появится в результатах карточки. При отказе используйте отдельный токен рекламодателя.
4. В разделе «Рекламные аккаунты» откройте настройки добавленного аккаунта и выберите запись из локального раздела «Организации». Она используется для группировки и команд по названию. Нажмите «Разрешить баланс и расходы в панели».
5. В разделе «Сводка» нажмите «Обновить». Для отдельного запроса в консоли выполните `Проверь баланс организации Альфа`, подставив название или псевдоним. Сверьте сумму и валюту с общим счётом в Директе. Если Яндекс отказывает в чтении общего счёта, смотрите причину и код рядом с показателем.
6. Для прогноза подтвердите, как в сумме общего счёта учитывается НДС, и укажите это в настройках общего счёта. При нескольких общих счетах введите ID нужного счёта. Его можно посмотреть в веб-интерфейсе Директа. [Общий счёт в Директе](https://yandex.ru/support/direct/ru/payments/shared-account)

### Аккаунты eLama

Аккаунт вида `porg-…` может открываться из личного Яндекс ID через «Выбрать организацию». Так eLama описывает вход в рекламный аккаунт в режиме организации. Управляющий доступ в Директе назначается отдельно в разделе «Ваши представители». Для подключения ориентируйтесь на тип, который подтвердил Яндекс в карточке. `SUBCLIENT` означает клиента агентства. Если требуются дополнительные права API на `porg-…`, eLama просит указать логин рекламного аккаунта и Яндекс ID в запросе в Службу Заботы. [Вход через Яндекс ID](https://help.elama.ru/article/77788), [доступ к API через eLama](https://help.elama.ru/article/82321), [управляющие аккаунты](https://yandex.ru/support/direct/ru/campaigns/mcc)

### Разрешения и консоль

«Эта веб-панель» разрешает операции кнопкам на этом сайте и его консоли команд. «Внешняя интеграция (API)» разрешает команды центральному проекту «Интерфейс», через который могут работать VoiceBot, Telegram и Discord. В разделе «Разрешения» выберите источник и область, затем отметьте нужные операции. «Весь каталог» применяется к спискам организаций и аккаунтов, финансовые чтения выдаются на конкретный аккаунт.

В консоли можно выбрать готовую фразу с названием записанной организации, выполнить её и увидеть результат. В режиме JSON можно проверить структурированную команду будущей интеграции. Консоль выполняет чтение с разрешениями панели.

## Хранилище токенов

В Windows модуль по умолчанию шифрует токен через DPAPI текущего пользователя. Запускайте процесс под той учётной записью Windows, под которой сохранили подключение. Для Linux или среды без доступного профиля DPAPI задайте `DIRECT_MODULE_MASTER_KEY` из отдельного хранилища секретов.

Следующая команда создаёт ключ Fernet для новой базы и помещает его в переменную текущего сеанса PowerShell.

```powershell
$env:DIRECT_MODULE_MASTER_KEY = (uv run --locked python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())")
```

Храните этот же ключ отдельно от базы и подавайте его при последующих запусках. При переносе базы с DPAPI на Linux повторно введите токены в разделе «Подключения» с настроенным ключом Fernet.

## Центральный интерфейс

Для вызова `/api/v1/commands` и `/api/v1/commands/text` задайте `DIRECT_MODULE_API_KEY` как случайную строку минимум из 32 букв и цифр ASCII. Выдайте нужные операции источнику «Внешняя интеграция (API)» в разделе «Разрешения». Ключ модуля передаётся в заголовке `Authorization: Bearer`. [Контракт команд](API_CONTRACT.md)

Веб-сервер слушает `127.0.0.1`. Локальная панель рассчитана на доверенную рабочую станцию. Для передачи доступа за пределы этого компьютера нужна отдельная серверная схема с аутентификацией администратора.

## Справочник людей и архив импорта

Добавляйте имена и телефоны в карточке организации. Раздел «Люди» показывает общий справочник и открывает нужную карточку. Из карточки также можно открыть настройку доступа для конкретного рекламного аккаунта.

Импорт индексирует строки с явно размеченными организациями. Явно названные колонки сайта, контактного лица и телефона используются при однозначном сопоставлении. Примечание организации предназначено для рабочих сведений. Полный XLSX, включая пароли и свободный текст, шифруется в SQLite отдельным ключом Fernet. Этот ключ защищён DPAPI текущего пользователя Windows или внешним ключом Fernet. Карточка показывает только ссылку на архив и координаты строк.

Для восстановления при необходимости используйте тот же профиль Windows или тот же внешний ключ. Команда создаёт незашифрованную копию на выбранном защищённом диске. Укажите новый путь вне репозитория.

```powershell
uv run --locked python -m direct_module.import_sheet restore 1 'X:\Protected\clients.xlsx'
```
